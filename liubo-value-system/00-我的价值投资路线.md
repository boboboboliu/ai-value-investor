# 我的价值投资路线

## 一、目标

我希望正式进入价值投资领域，用 AI 和程序员能力建立自己的长期投研系统。

我的目标不是短线炒股，而是长期理解优秀公司，建立自己的能力圈、估值体系和投资纪律。

## 二、核心原则

1. 不懂不投
2. 先研究企业，再看价格
3. 重视自由现金流
4. 重视 ROE / ROIC
5. 重视护城河
6. 重视管理层
7. 重视安全边际
8. 买入前必须写投资备忘录
9. 买入后必须跟踪核心假设
10. 判断错了要及时承认

## 三、第一阶段计划

### 第 1 周

- 阅读 ai-berkshire 的 README
- 阅读 investment-checklist
- 阅读 investment-team
- 建立自己的公司研究模板

### 第 2 周

- 选择 3 家公司做初步研究
- 每家公司写一页投资备忘录
- 建立财务指标表

### 第 3-4 周

- 做第一个 AI 财报分析工具
- 输入股票代码
- 自动输出核心财务指标
- 自动生成初步研究报告
